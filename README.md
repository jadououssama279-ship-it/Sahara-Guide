# Sahara Guide

[Live Prototype](https://oral-brown-6hpumnvrrc.edgeone.app/)

## Overview
Sahara Guide is a TravelTech platform developed for the Ramadan IA Hackathon. Its primary goal is to optimize travel budgets within the Guelmim-Oued Noun region while actively supporting and showcasing the region’s local cooperatives.

## Features
- Budget-optimized travel planning for the Guelmim-Oued Noun region.
- Discovery and support of local businesses and cooperatives.
- Intuitive interface for customizing trips and exploring itineraries.

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express

## Project Structure
```
Sahara-Guide/
├── client/         # React.js frontend application
└── server/         # Node.js/Express backend API
```

## Getting Started

### Prerequisites
- Node.js (v16 or later recommended)
- npm or yarn package manager

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jadououssama279-ship-it/Sahara-Guide.git
   cd Sahara-Guide
   ```

2. **Install client dependencies:**
   ```bash
   cd client
   npm install
   # or
   yarn install
   ```

3. **Install server dependencies:**
   ```bash
   cd ../server
   npm install
   # or
   yarn install
   ```

### Running the app

#### Start the backend server
```bash
cd server
npm start
# or
node index.js
```

#### Start the frontend app
Open a new terminal:
```bash
cd client
npm start
# or
yarn start
```

The default frontend app usually runs at `http://localhost:3000` and the backend on `http://localhost:5000` (configurable).

## Folder Structure Details

- `client/` — Contains all React.js code (components, pages, assets, etc.)  
- `server/` — Contains all Node.js/Express API code (routes, controllers, configuration, etc.)

Both folders include placeholder README.md files to help guide further development.
